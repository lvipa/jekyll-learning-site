# Учебный сайт на Jekyll

Персональный сайт для публикации через GitHub Pages.

## Локальный просмотр

1. Установите Ruby с RubyGems.
2. Выполните `bundle install`.
3. Запустите `bundle exec jekyll serve`.
4. Откройте `http://localhost:4000`.

## Публикация

После отправки репозитория на GitHub включите **Settings → Pages** и выберите публикацию из ветки `main`, папка `/(root)`.
